# MCWebviewBlocker
## Overview
MCWebviewBlocker blocks the intrusive pop-ups that appear in the bottom-right corner.<br>

### 概要
McAfee(本物)をインストールしていると画面右下に表示されるポップアップを無効化することができます。<br>
※設定くらい用意してくれればいいのに何年も前に項目を消した模様。

## Way to use
Please run the setup to perform the installation.<br>
For V1.0.0.0, either restart your PC or start the service manually.

### 使用方法
Setupを実行。<br>
V1.0.0.0ではインストールした後にPCを再起動するか、サービスから手動で起動してください。<br>

## Working
* Microsoft Windows 11 x64
* Microsoft Windows 11 Arm64
